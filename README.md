# YATAI

Site vitrine d'une échoppe japonaise de karaage et katsu-sando (projet de démonstration, marque fictive).

Réalisé par **Youssouf**, développeur web freelance, comme pièce de portfolio.

## Points clés

- Direction artistique « papier » : fond texturé, cartes inclinées, bords de papier déchiré générés en SVG
- Sceau japonais (hanko) dessiné en SVG avec effet d'encre
- Carte complète et présentation des six sauces maison
- Header qui change d'apparence au scroll, animations d'apparition
- 3 pages : accueil, carte, contact
- Responsive (mobile, tablette, desktop), sans framework ni étape de build

## Stack

HTML, CSS, JavaScript vanilla. Site statique, déployé sur Netlify.

## Lancer en local

Ouvrir `index.html` dans un navigateur.
